# Evals

These cases check safety, privacy, reflection, and Memory/State proposal boundaries. They are synthetic public-safe examples only and must not contain real journal data or private traces. They test boundary behavior, not clinical validity or therapeutic effectiveness.

Run cases manually using the expected behavior, prohibited behavior, and pass criteria in each table. See `EVALS.md` for the case index and walkthrough links.

Run schema validation with:

```powershell
python scripts/validate-json-schemas.py
```
