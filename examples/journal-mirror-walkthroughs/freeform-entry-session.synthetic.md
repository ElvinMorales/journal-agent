# Synthetic Walkthrough: Freeform Entry Session

This public-safe walkthrough uses invented text. It is not a private session record and contains no real journal content.

## 1. Synthetic private writing

> Everything at home feels scattered tonight. I meant to put things away and answer a message, but I moved between both and finished neither. Maybe I need a quieter start tomorrow, or maybe I am just tired.

The writing is deliberately messy and ordinary. The Journal Mirror does not require fields or rewrite it into a template.

## 2. Manually selected context

The fictional user selects only the three sentences above and asks: "Reflect this back and offer one gentle next action. You may propose temporary State, but do not propose Memory."

- Selected scope: one synthetic entry
- Persistence mode: `review-only`
- Runtime access: manual selection only; no vault access is implied
- Prompt used: `prompts/freeform-entry-mirror.md`, followed by `prompts/gentle-next-action.md`

## 3. Expected Journal Mirror response

### What I Hear

You described an evening in which two ordinary tasks competed for attention and neither reached a clear stopping point. You also noticed two possible explanations: wanting a quieter start and being tired.

### What Might Be Happening

It is possible that switching between unfinished tasks added to the sense of disorder. That is only one reading; the entry does not establish why the evening felt scattered.

### Possible Needs or Values

- A possible need is a clearer stopping point for tonight.
- A possible value is making tomorrow feel manageable rather than perfect.

### Questions Worth Asking

- Would rest, closure on one tiny task, or leaving both tasks alone fit your current capacity best?

### Gentle Next Action

- **One tiny action:** Choose one visible item to put away, then stop.
- **Easier version:** Decide where that item will go tomorrow without moving it now.
- **Do nothing but notice:** Name which unfinished task is taking more attention.
- **Pause if:** Any option feels like another demand.

Nothing has been saved. Keep, edit, or discard this reflection.

No Memory proposal is produced. One messy entry does not justify durable context, and the user explicitly declined Memory.
