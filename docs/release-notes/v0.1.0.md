# v0.1.0 Release Notes

## Summary

`v0.1.0` establishes `journal-agent` as a public reference implementation of the Agentic AI Artifact Taxonomy applied to a private journaling workflow.

This release is not a therapy product, mental health product, private journal database, app backend, PWA, or Obsidian plugin. It is a public-safe artifact system showing how reusable agent artifacts can support a private AI-assisted journaling companion while keeping private journal content outside the public repo.

## What Is Included

- README positioning as a taxonomy reference implementation.
- 14-bucket taxonomy mapping.
- Public/private architecture documentation.
- Decision record for keeping journal content outside the repo.
- v0.1.0 release checklist.
- Schema validation GitHub Action.
- Synthetic-only example audit.
- Clarified synthetic eval wording.

## Public / Private Boundary

The public repository contains reusable control-plane artifacts: instructions, prompts, schemas, guardrails, privacy rules, templates, evals, docs, and validation scripts.

Private journal content belongs outside the repo: in a private Obsidian vault, ignored local folders, or another user-controlled private system.

Do not commit real journal entries, private summaries, memory, state, therapy notes, crisis notes, logs, databases, screenshots, secrets, or identifying details.

See `docs/architecture.md` for the public/private architecture and `docs/decisions/0001-public-artifacts-private-journal.md` for the core boundary decision.

## Known Limits

- This release is documentation-first.
- It does not include a web app, hosted API, Obsidian plugin, PWA, or backend service.
- Runtime guidance is local/mobile-first.
- Evaluation is lightweight and qualitative.
- Capability module metadata can be improved in a later release.
